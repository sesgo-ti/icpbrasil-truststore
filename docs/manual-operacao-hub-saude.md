## 2. Visão Geral do Sistema

- **Finalidade e Objetivos: 
  -  Interoperar dados de saúde entre diferentes Sistemas de Saúde utilizando o padrão FHIR®, da rede pública e da privada, do estado de Goiás de forma a garantir a segurança, integridade e confidencialidade dos dados.

- **Principais Funcionalidades:**
    - Receber e enviar dados de saúde de diferentes Sistemas de Saúde utilizando o padrão FHIR®.
    - Processar e validar, incluindo conformidade com o padrão FHIR®, regras de negócio e políticas de segurança, os dados recebidos.
    - Garantir o acesso somente de usuários devidamente credenciados e autorizados.
    - Armazenar os dados de saúde de acordo com as políticas de segurança e conformidade.
